# FingerprintScreen Object

* `width` number - `screen.width` value.
* `height` number - `screen.height` value.
* `availWidth` number - `screen.availWidth` value.
* `availHeight` number - `screen.availHeight` value.
* `colorDepth` number - `screen.colorDepth` value.
* `pixelDepth` number - `screen.pixelDepth` value.
* `dpr` number - `window.devicePixelRatio` value.
* `maxTouchPoints` number - `navigator.maxTouchPoints` value.
